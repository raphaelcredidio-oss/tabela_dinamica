# Projeto 3 - Dashboard Interativo com Dash

Este projeto consiste na criação de uma aplicação web interativa utilizando a biblioteca **Dash** do Python, baseada na análise estatística de um conjunto de dados de e-commerce (`ecommerce_estatistica (2).csv`).

## 🛠️ Tecnologias Utilizadas
- Python 3.x
- Pandas
- Plotly
- Dash

## 📦 Como Instalar as Dependências

Clone este repositório e execute o seguinte comando no seu terminal para instalar as bibliotecas necessárias:

```bash
pip install pandas dash plotly
